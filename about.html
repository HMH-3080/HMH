Marsad — VPS fleet management

OPEN SOURCE 2026 — PRESENT SOLE CONTRIBUTOR

A self-hosted fleet management platform that dresses as a browser-based mini-OS desktop. Phoenix LiveView + Elixir/OTP: every managed server is held behind a supervised GenServer with a persistent SSH connection — so terminal, files, containers, services and metrics all stream through one persistent wire.

Desktop & terminal

  • Draggable windows, taskbar, app launcher over LiveView WebSockets
  • xterm.js SSH terminal — persistent PTY per window
  • SFTP explorer with a smart query language
  • Inline remote editing + syntax-highlighted previews

Ops & engineering

  • Docker / systemd / nginx panels + SSL expiry monitoring
  • Live metrics — per-core CPU, memory, disk, network I/O
  • AES-256-GCM credential vault via OTP :crypto
  • Allow-list regex validation on remote shell commands
