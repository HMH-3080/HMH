Marsad — VPS fleet management

OPEN SOURCE 2026 — PRESENT SOLE CONTRIBUTOR

Self-hosted platform that turns VPS fleet management into a browser-based mini-OS desktop. Built with Phoenix LiveView and Elixir/OTP (sole contributor, under the Arab-Open-Source organization): every managed server runs behind a supervised GenServer holding a persistent SSH connection — terminal, file explorer, Docker, systemd, nginx, and live metrics in one themeable UI.

Desktop & terminal

  • Draggable, resizable windows with taskbar and app launcher over LiveView WebSockets
  • xterm.js SSH terminal — one persistent PTY shell per window (vim, pipes, job control work natively)
  • SFTP file explorer with a smart query language — "exact phrase", -exclude, ext:conf, size:>10M, depth:3
  • Inline remote code editing with save-to-remote and syntax-highlighted previews
  • Offline mode: dedicated page plus automatic overlay when the connection drops

Ops & engineering

  • Docker panels — containers, images, Compose stacks, live resource stats, audit trail
  • systemd service control + nginx management with SSL-certificate expiry monitoring
  • Live metrics — per-core CPU, memory, disk, network I/O, process table with kill
  • One supervised ServerSession GenServer per server (Registry + DynamicSupervisor)
  • AES-256-GCM credential vault via OTP :crypto; TOFU host-key fingerprint records
  • Allow-list regex validation on every name interpolated into remote shell commands

EgyFy Parser — Local OCR Workspace

PRJ-14 / OSS 2026

Local OCR workspace for PDFs and scanned images built on Indra OCR — reads documents page by page and exports clean Markdown, text, JSON, and tables. Everything runs on the user's machine; documents never leave it. Zero-framework Python backend and a static JS client, published under the Arab-Open-Source organization (Apache-2.0).

What it does

  • Reads PDF, PNG, JPG, TIFF, WebP — auto-selects text layer, OCR, or a mix per page
  • Per-page review: line confidence, layout blocks, reading-order overlay, raw JSON
  • Exports Markdown, text, lines CSV, JSON, print-ready HTML, tables & complete ZIP
  • Clean-output mode strips layout markers and stray table pipes; LaTeX math as equations

Engineering

  • Single Python process — no framework, no database, no build step
  • Page cache shared by previews and exports: a page is never parsed twice
  • HTML/Markdown sanitization and table extraction covered by unit tests
  • Pinned OCR engine (Indra 0.3.2) with an offline --model-dir workflow
