## Variant: Swiss bold

### Design stance
Maximum typographic confidence — giant uppercase statements, thick rules, invert-on-hover rows. The work list is the design.

### Key choices
- Layout: 12-col discipline, 3px black rules, numbered sections with oversized numerals, full-bleed index rows.
- Typography: Inter 900 for statements, mono only for micro-labels and clocks.
- Color: pure black on white, one signal red reserved for tiny hits.
- Interaction: working category filter, full-row invert hover, live Cairo clock.

### Trade-offs
- Strong at: impact, scan speed, memorable identity.
- Weak at: warmth; long-form reading (articles need a quieter reader page); uppercase-everything can shout.

### Best for
- Positioning as a high-agency builder who ships; landing attention fast.
