## Variant: Editorial print

### Design stance
The portfolio is a printed engineering journal — folio, masthead, drop caps, marginalia — not a website that happens to hold text.

### Key choices
- Layout: centered measure, two-column body, sticky marginalia rail, table-of-contents index with dotted leaders.
- Typography: Newsreader serif for prose, JetBrains Mono only for folio/labels.
- Color: warm paper, ink, one rust accent.
- Interaction: reading-progress rule, jump-nav, hover states on the index.

### Trade-offs
- Strong at: reading experience, gravitas, differentiation from dev-portfolio sameness.
- Weak at: density (projects need a second volume/page), less "technical-system" signaling, long scroll.

### Best for
- Positioning as a thoughtful practitioner whose writing and dossiers matter.
